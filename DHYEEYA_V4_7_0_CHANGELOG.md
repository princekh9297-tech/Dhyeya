# DHYEYA v4.7.0 — Intelligence + Motion Upgrade

## Preserved
- Existing authentication, PostgreSQL architecture, question imports, tests, attempts, revision vault, planner, leaderboard, battles and Chrome translation workflow.

- BPSC Preparation Index based on accuracy, consistency, breadth, speed and revision pressure.
- Subject-level weak-area diagnosis.
- Adaptive practice endpoint prioritizing weak/unmastered questions.
- Spaced revision progression (1/3/7/15/30 day intervals) with revision result tracking.
- Question intelligence metadata: quality score, concept tag, PYQ frequency, learning objective.
- Admin platform intelligence dashboard: question-bank health, learner activity and subject coverage.
- Premium motion language across dashboard and interaction surfaces.
- Reduced-motion accessibility support.
- New v4.7 frontend modules loaded additively.

- Motion uses CSS transforms/opacity and avoids heavy continuous effects.
- Adaptive queries are database-backed and bounded.
