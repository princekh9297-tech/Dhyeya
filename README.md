# DHYEYA V3 — Production Foundation

This package upgrades DHYEYA to an authentication-first, PostgreSQL-backed production foundation.

## Included
- Student ID / username / email + password login
- Logged-out access gate: student features are hidden until authenticated
- Server-side auth middleware on protected APIs
- Admin-only middleware and Admin Console
- Admin student generation, activation/blocking, password reset, content import and test creation
- Admin broadcast notifications with student popup delivery
- Persistent quiz sessions / resume
- PostgreSQL-backed planner, attempts, question attempts, revision, XP, leaderboard and profile
- Battle Arena foundation: Challenge Everyone, first-accept matchmaking, server-authoritative questions/scoring, battle history
- Online presence heartbeat
- Dynamic time-based greeting + saved student name + motivational quote
- Responsive mobile/iPad UI
- Automatic schema initialization on startup; no Render Shell required

## Render
Build command:
`npm install`

Start command:
`npm start`

Required environment variables:
- DATABASE_URL
- JWT_SECRET
- NODE_ENV=production
- ADMIN_USERNAME
- ADMIN_PASSWORD
- ADMIN_EMAIL
- ADMIN_NAME

Optional:
- `ALLOW_SELF_REGISTER=true` to enable public registration. Default is disabled; production accounts should be generated by Admin Console.

## Important
Core data is stored in PostgreSQL. Do not put database credentials or AI API keys in the frontend.

The package is additive to the existing question/test architecture; import the real test/question bank through Admin Console rather than inventing replacement content.
