# DHYEYA V4.2.2 — iPad Navigator + Theme UX

## Changes
- iPad/tablet quiz navigator now behaves as a right-side drawer in both portrait and landscape orientations.
- Question content uses the full available width when the navigator is closed.
- Added a compact Question Navigator button beside the question number.
- Selecting a question from the navigator immediately jumps to it and closes the drawer.
- Added Escape-key close support for the navigator.
- Navigator state styling remains: green Answered, theme accent Current, grey Not Attempted, red Marked for Review.
- Existing bottom quiz controls are preserved.
- Existing six-theme single-click cycle is preserved.
- Theme indicator remains a temporary 1.5-second label after switching.
- Theme 4 remains the default and the saved theme persists through reloads/unload.
- No question-bank, import, scoring, authentication, or database changes.
