# DHYEYA v4.6.0 — English Question Upload + Chrome Translation

## Admin Question Upload
- English-only question ingestion.
- TXT, JSON, CSV and PDF supported.
- TXT parser supports numbered questions, A-E options, Answer, Explanation and optional Subject/Topic/Year/Difficulty/Source/ID metadata.
- Server-side UTF-8, Unicode, Hindi/Devanagari and duplicate validation.
- Existing question matches are reported before import.
- 50,000-question logical import limit retained; upload limit increased to 50 MB.
- Chunked database import remains in place.
- Hindi question/explanation fields are not accepted or generated by the upload pipeline.
- Question editor is English-only.
- Added downloadable TXT template.

## Student Quiz
- Quiz questions are rendered from the English master copy.
- Removed stored Hindi/bilingual rendering from the active quiz flow.
- Added “Translate in Chrome” helper button.
- Chrome remains responsible for page translation into Hindi or other available languages.
- Scoring, answer indexes, timers, attempts and revision logic remain language-independent.

## Compatibility
- Existing PostgreSQL schema is preserved.
- Existing student accounts, tests, attempts and historical records are not reset.
- Legacy Hindi columns may remain in the database for backward compatibility, but new admin imports write English-only content.
